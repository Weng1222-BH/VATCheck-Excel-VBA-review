# 增值税专票双表一键核对工具

开发接手请先读唯一当前入口：[STATUS.md](STATUS.md)。本 README 说明 Stage 1 的安装与使用；Stage 2 当前规格和检查点由入口导航。

Windows Excel VBA 版本。主入口是 `VATCheck_Start`。可独立运行，也可装入 `Personal.xlsb` 长期使用。A、B 在一个非模态窗体中左右同时显示，不设定时器或后台监控。

## 最快试用

1. 打开 `release/VATCheck.xlsm`，仅对此文件允许运行宏。
2. 业务文件可以尚未打开；如已经打开，工具会复用当前 Excel 实例中的同一文件，保留未保存编辑。
3. 按 **Alt+F8**，运行 `VATCheck_Start`。
4. 左右分别点击“选择 Excel…”打开本地文件选择器，选择文件后再选 Sheet。当前实例未打开的文件会在该实例中打开，已打开的相同路径直接复用。唯一表头自动定位；同名表头出现多次时，必须在“目标字段”列表中明确选地址和列。
5. 保持窗体打开，在 Excel 中选择**一个**已正确填色的单元格，回到窗体点击任意一侧“从选中单元格读取”。两个颜色块会同步显示。
6. 点击“一键核对”。修改金额、颜色或公式后，再次点击核对。增删 Sheet 后可点击“刷新 Sheet 列表”。切换文件时，直接点击对应侧的“选择 Excel…”，另一侧保持不变。

文件路径悬停可见；取消文件选择保留原绑定，打开失败也保留原有效绑定。选择器仅提供 Excel 工作簿；工具自身、Personal.xlsb 和加载项不能作为业务表。独立启动的另一个 Excel 进程不属于当前实例，不能读取其未保存修改。

关闭业务工作簿时，工具使对应侧的文件、Sheet、字段及定位失效，保留另一侧和共用颜色，窗体可继续选择新文件。失效从 Excel 的关闭请求事件开始；若随后取消了关闭，重新选择同一文件即可复用。请保持工具宿主（VATCheck.xlsm 或 Personal.xlsb）及 Excel 本身运行。文件切换不保存或关闭原业务工作簿。

## 安装到 Personal.xlsb（推荐日常使用）

这是一次性安装，**不需要开启“信任对 VBA 工程对象模型的访问”**。导入和使用宏是不同权限；该开关只供开发脚本自动构建使用。

1. 如果尚无 Personal.xlsb：Excel → 开发工具 → 录制宏，“保存在”选择“个人宏工作簿”，立即停止录制。退出 Excel 时保存个人宏工作簿，再重新打开 Excel。
2. 按 **Alt+F11** 打开 VBA 编辑器，在左侧选择 `VBAProject (PERSONAL.XLSB)`。
3. 菜单“文件 → 导入文件”，依次导入发布目录里的：
   - `modVATCheck.bas`
   - `frmVATCheck.frm`
4. `frmVATCheck.frx` 必须与 `.frm` 保持在同一目录，导入窗体时会自动读取，不要单独导入 `.frx`。
5. 在 VBA 编辑器执行“调试 → 编译 VBAProject”。保存 **PERSONAL.XLSB**。这里保存的是您安装的工具代码，核对功能本身不执行保存。
6. 返回 Excel，按 **Alt+F8**，运行 `PERSONAL.XLSB!VATCheck_Start`。也可在“文件 → 选项 → 快速访问工具栏 → 从下列位置选择命令：宏”中添加此宏。

已有同名模块或窗体时，请先备份 Personal.xlsb，再替换旧版本；不要导入成 `modVATCheck1` 或 `frmVATCheck1`。不要同时运行独立版和 Personal 版，以免出现两个工具窗口。

## 第一次测试（不使用真实业务数据）

新建两份空白工作簿，分别保存为 A.xlsx、B.xlsx，再填写以下样例（修改可不保存）：

| 工作簿 | 单元格 | 内容 | 填充 |
|---|---|---|---|
| A | K3 | `有效抵扣税额*` | 无 |
| A | K4 | 数值 `0.1` | 绿色 |
| A | K5 | 数值 `0.2` | 与 K4 相同的绿色 |
| A | K6 | 数值 `999` | 无 |
| B | AA5 | `税额` | 无 |
| B | AA6 | 数值 `0.3` | 与 K4 相同的绿色 |

也可以人工把对应整行填色；工具只读 K 或 AA 列的目标单元格。

依照“最快试用”操作，选择 A、B 和各自 Sheet，选 A!K4 读取绿色：

1. 核对应显示：**一致，A ¥0.30 / 2 行，B ¥0.30 / 1 行**。列应分别显示“第11列（K列）”与“第27列（AA列）”。
2. 把 B!AA6 改为 `0.2`，**不保存**，再次核对：**A 比 B 多 ¥0.10**。
3. 保留 A!K5 的绿色，清空金额，再次核对：**有效金额部分核对不一致**，A ¥0.10、B ¥0.20，警告指向 A 的 `K5`；A 完成色 2 行、实际计入 1 行、空金额未计入 1 行。
4. 给 A!M3 也写入完全相同的 `有效抵扣税额*`，重新选择 A 的 Sheet：应出现两个候选，工具不得默认选择。
5. 关闭 A.xlsx：A 侧失效，B 侧和窗体继续保留。点击 A 侧“选择 Excel…”选另一份带目标表头的文件，选 Sheet、定位后应可继续核对。取消选择不应清空 B。

## 已确定的计算口径

- A 精确匹配 `有效抵扣税额*`（末尾星号是实际字符），B 精确匹配 `税额`。不自动去空格或模糊匹配。查找范围为所选 Sheet 的已用区域，表头不限于第一行。
- 从**所选表头下一行**一直读到该 Sheet 已用区域末行，只检查目标列。这样能捕获已经填色却没有金额的尾行。
- 纯色样本作为两表共同的完成颜色；以单元格当前显示填充色匹配，支持手工填色及条件格式。无填充与白色填充有区别。隐藏行、筛选掉的行仍参与。
- 不猜测哪些行是“合计”“备注”或哪个区域是明细；表头下方目标列中所有完成颜色单元格都按规则检查。请不要把不应参与的合计行填成完成颜色。
- 数值（包括返回数值的公式）经 `CDec(Value2)` 转为 **Variant/Decimal** 后累加、相减、精确比较；不使用浮点容差，不按行四舍五入。金额至少显示两位小数，实际存在分以下精度时完整保留，避免把非零差额显示成零。
- Excel 原始数值本身仍受 Excel 的数值存储精度限制；Decimal 可以消除工具累加时的浮点误差，不能恢复 Excel 已丢失的原始数字。
- 完成色的**真正空单元格**作为非致命警告跳过，列出所有位置，其他正常金额继续汇总；有此警告时结论使用“有效金额部分核对一致/不一致”。同时区分完成色行数、实际计入核算行数、空金额未计入行数。
- 只放宽真正空单元格。数字文本、公式空字符串、其他文本、布尔值、Excel 错误、Decimal 转换/累加溢出、已完成合并单元格等仍阻止结论，并给出位置。警告与致命异常并存时仍阻断，不能宣称有效金额部分一致。
- 两边完成行数只展示；即使行数不同，只要金额完全相等就一致。两边都没有完成记录时，展示零合计一致，同时明确提示零记录。
- 读取当前公式结果，不强制重算或刷新外部连接。Excel 正在计算/尚待计算时阻止核对；使用手动计算或外部数据的文件，应自行先完成 F9 计算或数据更新。
- 结果是点击时的快照，窗体不会自动监视之后的编辑。换表、换字段或重新取色时会清除旧结果。
- 工作簿已关闭或表头被修改时，须重新选择，不按旧列猜测。隐藏 Sheet 可读取；图表 Sheet 会明确提示不能核对。

## 只读边界

正式运行代码只有 `modVATCheck` 和 `frmVATCheck`。只在用户明确选择文件后打开或复用工作簿，不修改业务数据、公式、填充色，不插入/删除行列，不保存或关闭业务文件，不安装后台任务。打开新文件时不更新外部链接，并临时禁止该次打开文件的宏，随后恢复原设置。关闭事件仅用于使文件绑定失效，不自动进行核对。

开发构建脚本只写本项目发布文件。测试模块只创建、修改和关闭它自己新建的临时工作簿，**不包含在正式工具中**。

## 开发与重新构建

入口：`src/modVATCheck.bas`（UTF-8 核心逻辑）、`src/frmVATCheck.vba`（UTF-8 窗体代码）、`tests/modVATTests.bas`（原生 Excel 自测）。

在项目根目录执行：

```powershell
# 需要本机 Excel 已允许程序访问 VBA 工程。
./tools/build.ps1 -Test

# 只运行完整测试，不替换现有 release。
./tools/build.ps1 -TestOnly
```

脚本拒绝覆盖既有 `release/VATCheck.xlsm`；重新构建前手动将旧发布物移到备份目录。经过明确授权，普通 Office 安装可以用 `-TemporaryTrust` 临时设置 VBA 工程访问；脚本在 finally 恢复旧值。若安装环境不识别该注册表设置，使用 Excel 界面临时设置，验证后恢复。

发布版 `.bas/.frm/.frx` 由 Excel 原生导出，适合当前 Windows VBA 编辑器导入；`src` 中 UTF-8 源文件供维护阅读，避免直接用 VBA 导入 UTF-8 导致中文乱码。无需 Python、外部服务、WinAPI 声明或额外加载项。

自测运行结果保存在 `tests/excel-test-results.txt`。发布复验可运行 `tests/verify-release.ps1`，结果在 `tests/release-verification.txt`。测试需要允许 VBA 工程访问，现有明确授权下可临时使用 `-TemporaryTrust`，结束后核实恢复；无需 Bypass。最新验证状态请看 [STATUS.md](STATUS.md)，历史交接记录保存在 `archive/docs-cleanup-20260911/`。
